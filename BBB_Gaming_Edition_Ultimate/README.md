# BBB Gaming Edition Ultimate 3.0
Android landscape companion app with:
- Dashboard and navigation
- Local crosshair preview with size/gap/color controls
- Training timer
- Local PUBG Mobile / CODM sensitivity notes and profiles
- Saved touch-control notes
- Basic device and app-process memory information
- GitHub Actions debug APK workflow

Limitations: no game injection, cheats, anti-cheat bypass, actual FPS reading from another app, in-game FOV/sensitivity changes, or overlay. Crosshair preview is inside this app only.

Build: push to main/master or manually run the workflow in GitHub Actions. Download the APK from the run's Artifacts section.
